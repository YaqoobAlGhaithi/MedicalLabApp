## 📂 2. شرح المجلدات والملفات الرئيسية

### 🔹 مجلد `.github/workflows/`
- **`android-build.yml`**: ملف أتمتة CI/CD عبر GitHub Actions. يقوم ببناء كود الويب بـ Vite، مزامنة حزمة Capacitor، إعداد Java JDK 17، وتوليد ملف `app-debug.apk` ورفعه كملف قابل للتحميل المباشر.

### 🔹 مجلد `src/components/common/`
يحتوي على عناصر الواجهة التي يعاد استخدامها في أكثر من شاشة:
- **`Header.tsx`**: الشريط العلوي للشاشات الفرعية، يحتوي على زر الرجوع، عنوان الصفحة، زر القائمة للأجهزة المحمولة، وحالة المستخدم.
- **`Logo.tsx`**: مكون متجهي لرسم شعار عيادة ومختبرات المنار بدقة عالية وألوان الهوية الطبية.
- **`MobileBottomNav.tsx`**: شريط الملاحة السفلي المخصص للأندرويد، يضم 5 أزرار بمساحات لمسية تفوق 48px وزر مركزي بارز لإضافة الفواتير.
- **`MobileSidebarDrawer.tsx`**: القائمة الجانبية المنزلقة للأجهزة الذكية (Android Drawer) تتضمن روابط التنقل، بيانات الطبيب المناوب، زر الخروج، ومعلومات الدعم.
- **`Sidebar.tsx`**: الشريط الجانبي للشاشات الكبيرة يدعم الطي التدريجي (Collapsible) بين 256px و 80px مع تلميحات عائمة (Tooltips) وحفظ الحالة في `localStorage`.
- **`PrintModal.tsx`**: نافذة منبثقة للمعاينة الطبية قبل الطباعة، تدعم الطباعة المباشرة عبر المتصفح وتوليد ملفات PDF.

### 🔹 مجلد `src/components/dashboard/`
يحتوي على المكونات الفرعية المخصصة لشاشة لوحة التحكم:
- **`DashboardHeader.tsx`**: شريط البحث العلوي، زر طي الشريط الجانبي، تبديل وضع الخصوصية، وتصفية النطاق الزمني.
- **`DashboardKpis.tsx`**: شبكة بطاقات الإحصائيات (الإيرادات، التقارير، المرضى، العينات المعلقة، الحالات الحرجة، وقت الإنجاز)، متجاوبة في شبكة ثنائية للأندرويد.
- **`DashboardCharts.tsx`**: رسوم بيانية ومخططات إحصائية باستخدام Recharts.
- **`DashboardDoctorStats.tsx`**: بطاقة إحصائيات توزيع الإحالات الطبية حسب الأطباء والعيادات الخارجية.
- **`dashboardTypes.ts`**: واجهات الخصائص والأنواع المشتركة بين مكونات لوحة التحكم.

### 🔹 مجلد `src/components/screens/`
يمثل الشاشات المستقلة في التطبيق ويتم التبديل بينها عبر معرّف `activeScreen`:
- **`DashboardScreen.tsx`**: شاشة لوحة التحكم الرئيسية ومركز التحليلات.
- **`AddInvoiceScreen.tsx`**: شاشة متعددة المراحل لتسجيل المريض وإدخال نتائج الفحوصات وإصدار الفاتورة.
- **`ReportsListScreen.tsx`**: جدول واستعراض التقارير المخبرية مع البحث والتصفية وحالات الاعتماد.
- **`PatientProfileScreen.tsx`**: قاعدة بيانات المراجعين وسجل الفحوصات والزيارات السابقة لكل مريض.
- **`ReportViewScreen.tsx`**: نموذج العرض الكامل والطباعة لتقرير فحص مخبري محدد.
- **`BackupSettingsScreen.tsx`**: شاشة تصدير واستيراد النسخ الاحتياطية (JSON) وضبط هوية المختبر.
- **`LoginScreen.tsx`**: شاشة تسجيل الدخول والتحقق من حساب الكادر الطبي.
- **`SplashScreen.tsx`**: شاشة البداية والترحيب تظهر عند تشغيل التطبيق لأول مرة.

### 🔹 مجلد `src/context/`
- **`AppContext.tsx`**: شريان إدارة الحالة (State Management) للتطبيق، يوفر البيانات ودوال التحديث لجميع المكونات دون الحاجة إلى تمرير الخصائص اليدوي (Props Drilling)، ويدير التخزين المحلي لبيانات المرضى والفحوصات وإعدادات الشريط الجانبي.

### 🔹 مجلد `src/data/`
- **`mockData.ts`**: عينات أولية لبيانات المختبر (المرضى، الأطباء، التقارير الافتراضية، الإعدادات).
- **`referenceRanges.ts`**: القائمة القياسية للفحوصات الطبية والوحدات والمعدلات الطبيعية والحدود الحرجة.

### 🔹 مجلد `src/types/`
- **`index.ts`**: تعريفات واجهات TypeScript الصارمة: `Patient`, `LabReport`, `TestResultItem`, `TestDefinition`, `Doctor`, `LabSettings`, `ActiveScreen`.

### 🔹 ملفات الجذر والإعدادات (Root Configuration)
- **`App.tsx`**: المكون الرئيسي وموجه الشاشات وعارض النوافذ المنبثقة وشريط الملاحة للأندرويد.
- **`capacitor.config.ts`**: إعدادات Capacitor لتوليد تطبيق أندرويد بالمعرف `com.almnar.app`.
- **`index.html`**: الصفحة الرئيسية متضمنة وسوم الميتا الطبية، ولون شريط الحالة `#002e5b`، وتوجيه RTL.
- **`vite.config.ts`**: إعدادات بيئة التطوير والبناء والتوافق مع Tailwind CSS و React.
