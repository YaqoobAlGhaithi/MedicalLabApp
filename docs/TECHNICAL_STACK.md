## ⚙️ 4. محركات البناء والتحقق (Build & Tooling Workflow)

### أ. التحقق البرمجي (Linting & Type-Checking):
يتم فحص خلو الكود من الأخطاء النمطية عبر:
```bash
npm run lint
# يعادل: tsc --noEmit
```
يضمن هذا الأمر عدم وجود أي أخطاء في واجهات البيانات أو المتغيرات الناقصة.

### ب. البناء لبيئة الويب (Web Production Build):
```bash
npm run build
# يعادل: vite build
```
يقوم Vite بضغط وتحسين الأصول البرمجية ووضع المخرجات داخل مجلد `/dist`، لتكون جاهزة للمتصفح أو المزامنة مع كاباسيتور.

### ج. أداة أندرويد Gradle و Java JDK:
- **إصدار Java المستهدف:** OpenJDK 17 (Zulu).
- **محرك بناء أندرويد:** Gradle Wrapper (`./gradlew`).
- **نوع الحزمة المنتجة:** `app-debug.apk` (قابلة للترقية لـ `release` أو `AAB`).
